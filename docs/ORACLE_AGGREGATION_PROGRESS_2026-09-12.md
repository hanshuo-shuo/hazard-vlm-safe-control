## 当前最重要的科学结果

现在可以支持的窄主张是：**即使粗空间监督目标被完美预测，分别池化属性与动作足迹的
接口仍会造成实际决策损失；同源 oracle 分解能把这种损失与模型误差、监督源栅格差异分开。**

这不是协方差恒等式的新理论，也不是所有低分辨率模型或关系头的不可能性证明。
当前证据限于给定正常合成分布、四候选和公开成本公式；跨任务迁移仍未建立。

| 对比 | 发现 IID（2,000 场景） | 一次新确认 IID（2,000 场景） |
|---|---:|---:|
| 固定模型已选动作：pool512/ref512 危险标签变化 | 3.68% | 3.22% |
| 同一足迹下更精细属性检查导致的标签变化 | 0.05% | 0.15% |
| pool512 oracle 自行选择后丢失的安全机会 / 全部场景 | 72/2,000，3.60 pp | 63/2,000，3.15 pp |
| 完美实际 target64 oracle 丢失的安全机会 / 全部场景 | 60/2,000，3.00 pp | 54/2,000，2.70 pp |
| 边界交叠且小裕度 / 较大裕度的标签变化率 | 37.84% / 3.87% | 40.57% / 3.26% |

固定模型动作统计包含五模型共享场景，绝不能将 10,000 个 model–scene 条目当独立样本。
oracle 自行选择只有 2,000 个场景。新确认的 pool512 oracle 接受 1,529，观察到危险 0；
target64 oracle 接受 1,540，其中危险 2；直接参考有 1,592 个安全机会。
这些观察不是新的风险证书。新确认模型经验危险率 1.03%、η=96.77%；之前 E3 的
1.07%、96.93% 和原认证来自另一数据集，不混写。

## 三项预测与一次透明的统计加强

发现数据为已经消费的 E3 IID/新外观各 2,000 场景。全部比较使用同一 512 参考足迹。
每级重算 A/C/D 公式，C 的非线性不能用两通道暴露误差线性替代。固定选择与各级重选分开。

有实质信号后，新协议在生成新记录前固定 2,000 IID 场景、五个原 checkpoint 和三个预测：

1. 数值检查也保留安全候选时，pool512 oracle 丢失安全机会的概率下界 >1%。
   结果 **61/2,000**，精确单侧下界 **2.2869%**。
2. 模型已选动作的池化标签变化主要为保守方向，比例下界 >90%。
   原统计 322/322，但 bootstrap 因零反例退化为 100% 下界，不能当总体确定性。
3. 边界交叠下，小裕度组较大裕度组的标签变化率差的下界 >10 pp。
   实际差 **37.3080 pp**，交叉 bootstrap 单侧下界 **26.0586 pp**。

方向检验另加更严格的场景级要求：有任一变化的场景中，五个模型的所有变化都需保守。

## 有符号误差与实际含义

IID 发现数据的平均成本项分别为池化 +.001807、源栅格 −.000653、模型 −.000292。
新外观下分别为 +.002060、−.000714、−.001453：总有符号误差仅 −.000108，但绝对误差
仍为 .003102。模型与测量误差有部分抵消；不能把绝对值加总后写成各自“解释百分比”。
学习模型比完美目标 oracle 使用了更多安全机会，也接受了更多危险动作，并非全面胜过 oracle。
