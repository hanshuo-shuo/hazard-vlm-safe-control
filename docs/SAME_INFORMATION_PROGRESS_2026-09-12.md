## 实际结果：恢复与损害一起报告

所有处理得到相同的 16×16 粗场和 F512。原逐格均匀处理、一个发现集确定的成本偏移，
与固定 Parker–Youngs PLIC 比较。PLIC 方向仅来自粗邻域，每格面积比例守恒，不读取
真实形状参数、高分辨率属性或 oracle 法线。它是既有的一阶重建思想，不是我们的新算法。

开发只用已经消费的 IID 发现集 2,000 场景；实现和偏移随后锁定。评价使用已经消费的
2,000 场景确认集，明确标记为**追加基线分析**，不追认为 untouched 或第三轮机制确认。
原来的三个确认主张和原文件均没有改写。

| 输入 | 处理 | 恢复原安全机会 | 新损失原安全机会 | 新增危险接受 | 接受中危险率 | η |
|---|---|---:|---:|---:|---:|---:|
| 完美 target64，2,000 场景 | 均匀 | 0 | 0 | 0 | 0.13% | 96.61% |
| | 全局偏移 .001 | 6 | 0 | 3 | 0.32% | 96.98% |
| | PLIC | **44** | **0** | **16** | **1.13%** | **99.37%** |
| 五模型共享 2,000 场景 | 均匀 | 0 | 0 | 0 | 1.03% | 96.77% |
| | 共享偏移 0 | 0 | 0 | 0 | 1.03% | 96.77% |
| | PLIC | **83** | **0** | **43** | **1.56%** | **97.81%** |

五模型的数字汇总 10,000 个 model–scene 条目，但只有 2,000 个独立场景；不能混淆分母。
完美目标 PLIC 恢复 44/54 个机会，剩余损失 10；危险接受总数从 2 增至 18。
模型轨道安全接受净增 .83 pp，描述性交叉 95% 区间 [.51,1.19] pp；新增危险接受 .43 pp，
区间 [.20,.69] pp。机会恢复不是无代价安全改进，原证书不能继承。

偏移的选择约束是在发现集不增加危险接受数，PLIC 没有相同的拟合约束。因此选定点不是
matched-risk 胜负对照。完整偏移开发曲线保留；更大偏移可恢复更多，也承担更多风险。
我们没有根据追加集再选第二个偏移。

## 对机制的加强与限制

PLIC 用同一粗信息恢复大量机会，说明原均匀解释没有利用完的空间结构确实存在。
不能继续把原 54 个损失写成粗表征不可消除的误差下限，也不能宣称必须提升表征分辨率。
同时，新危险接受表明，重建不是可直接部署的安全修复。

新增 43 个危险模型事件中，**25 个**在同一动作上同时满足：原模型/测量误差异号，
重建后测量绝对误差改善，而总绝对误差变差。其余 18 个保留，不能用抵消解释一切。
按场景/模型顺序第一个这样的事件：

| 同一动作上的量 | 均匀解释 | PLIC |
|---|---:|---:|
| 真实参考成本 | .024972 | .024972 |
| 完美目标估计 | .031961 | .021431 |
| 模型估计 | .021279 | .016964 |
| 目标测量误差 | +.006989 | −.003541 |
| 模型相对目标误差 | −.010682 | −.004467 |
| 放行决定 | 拒绝 | 接受，且真实危险 |

这个例子中两个绝对分量都改善，但原来的异号抵消消失了。完整逐事件记录和独立计数保留，
不是从两张均值表推断机制。
