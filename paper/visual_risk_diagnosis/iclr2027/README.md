# Anonymous manuscript source

Title: **When Perfect Coarse Predictions Are Not Enough for Action Evaluation**.

This is an unsubmitted working manuscript using the official ICLR 2027 style.
It is a manuscript source bundle, not the complete anonymous experimental code
supplement. Authorship and human review of AI-assisted contributions remain to
be finalized before any actual submission.

The official `.sty` and `.bst` files are unchanged. `main.tex` replaces only the
default status words with “Working draft -- not submitted”; dimensions, fonts
and review line numbering are retained. Remove this draft-status override when
preparing a real submission, after the authors have made that decision.

With TeX Live (tested with 2026), run:

```bash
bash build.sh
```

The PDF is generated at `build/main.pdf`. All required manuscript figures and
the bibliography are included. `case_table.tex` is the fixed numeric illustration
computed from the preserved event archive; building this manuscript performs no
new experiment, fit or data generation. `matched_table.tex` and the fourth figure
come from the separately frozen full-threshold analysis.

The main text separates a prior prospective confirmation from a retrospective
same-information baseline comparison. The latter uses consumed data, adds no
training or scenes, and inherits no earlier risk certificate. The complete
development offset bank and harmful reconstruction outcomes are retained in the
research archive. The manuscript does not claim representation impossibility,
universal transfer, or a risk-free repair.

The retrospective comparison applies identical empirical risk ceilings to
complete threshold families. It finds clearer exact-target gains, but does not
establish a stable learned advantage across the inspected range. The operational
continuation screen fails and generates no score-superiority follow-up. A later
separate input-field by aggregator question is frozen and tested on one new
2,000-scene bank: the reconstruction's safe-accept gain is attenuated by 2.16
percentage points with learned input (one-sided upper bound -1.64 pp). The old
stop and its negative comparison are preserved. Full-cohort error opposition
remains an oracle diagnostic, while actual four-cell module interventions are
distinguished from non-deployable algebraic residual hybrids. The paper is
positioned as a controlled diagnostic case study with two contributions; the
reconstruction is an explanatory intervention, not an independently validated
decoder-selection contribution. Venue suitability remains a human research judgment.
